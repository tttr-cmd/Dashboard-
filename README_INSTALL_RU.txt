LifePilot — версия для установки на главный экран Android

Важно: это пока не APK-файл. Чтобы приложение устанавливалось как настоящее приложение через Chrome, файлы нужно разместить на сайте с HTTPS. Если просто открыть index.html из папки Downloads, Chrome может не показать «Установить приложение», а запись голоса может не работать.

Как установить после размещения на HTTPS:
1. Откройте ссылку сайта в Chrome на телефоне.
2. Нажмите ⋮ → «Установить приложение» или «Добавить на главный экран».
3. Запускайте LifePilot через появившийся значок. После первого открытия оболочка приложения может работать офлайн.

Данные хранятся локально в браузере телефона и не синхронизируются автоматически. Регулярно делайте резервную копию в самой программе. Очистка данных браузера может удалить записи.
